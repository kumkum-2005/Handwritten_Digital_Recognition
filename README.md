# ✍️ Handwritten Digit Recognition

## 📌 Project Overview

Handwritten Digit Recognition is a Machine Learning project that recognizes handwritten digits from images and predicts the digit from **0 to 9**.

The project uses image processing and machine learning techniques to classify handwritten numbers automatically.

## 🎯 Objective

- Recognize handwritten digits from images.
- Train a machine learning model for digit classification.
- Predict digits from new handwritten images.
- Demonstrate the use of image processing and machine learning.

## ✨ Features

- Handwritten digit recognition
- Image preprocessing
- Machine Learning classification
- Prediction of digits from 0–9
- Simple and user-friendly interface
- Fast prediction

## 🛠️ Technologies Used

- Python
- Machine Learning
- NumPy
- Pandas
- OpenCV
- Scikit-learn
- Matplotlib
- Tkinter / Flask

## ⚙️ How It Works

```text
Input handwritten image
        ↓
Image preprocessing
        ↓
Resize and normalize image
        ↓
Feature extraction
        ↓
Trained ML model
        ↓
Digit prediction
        ↓
Display predicted digit
```

## 🚀 Installation

### 1. Clone the Repository

```bash
git clone https://github.com/kumkum-2005/Handwritten_Digital_Recognition.git
```

### 2. Open the Project

```bash
cd Handwritten_Digital_Recognition
```

### 3. Install Required Libraries

```bash
pip install -r requirements.txt
```

### 4. Run the Application

```bash
python app.py
```
